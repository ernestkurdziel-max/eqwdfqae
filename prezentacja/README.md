# Mózgowe porażenie dziecięce — metody specjalne fizjoterapii

Prezentacja projektowa (przedmiot: *Metody specjalne fizjoterapii*) dotycząca
mózgowego porażenia dziecięcego (MPD) u pacjenta pediatrycznego: objawy, problemy
funkcjonalne oraz przegląd wybranych metod usprawniania.

## Plik do pobrania

- **`Mozgowe_porazenie_dzieciece_metody_fizjoterapii.pptx`** — gotowa prezentacja
  PowerPoint (22 slajdy, format 16:9).

## Zawartość (22 slajdy)

1. Slajd tytułowy
2. Cel i zakres pracy
3. Definicja MPD
4. Etiologia — przyczyny i czynniki ryzyka
5. Epidemiologia
6. Klasyfikacja postaci klinicznych (+ GMFCS)
7. Objawy ruchowe
8. Zaburzenia współistniejące
9. Problemy funkcjonalne
10. Diagnostyka i ocena funkcjonalna
11. Znaczenie i zasady rehabilitacji
12. Przerywnik: część II — metody
13. NDT-Bobath
14. PNF
15. Metoda Peto (nauczanie kierowane)
16. Ruch Rozwijający Weroniki Sherborne
17. Integracja sensoryczna (SI)
18. Zestawienie metod
19. Wnioski
20. Bibliografia — książki
21. Bibliografia — artykuły
22. Zakończenie

> **Uwaga terminologiczna:** temat opracowano jako *mózgowe (dziecięce) porażenie
> mózgowe* (ang. *cerebral palsy*), ponieważ to właśnie w tej jednostce chorobowej
> stosuje się wszystkie wskazane metody (NDT-Bobath, PNF, Peto, Sherborne, SI).

## Ponowne wygenerowanie pliku

```bash
pip install python-pptx
python build_prezentacja.py
```

Ilustracje i tła znajdują się w katalogu `assets/`.
