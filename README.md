# CV – Ernest Kurdziel

Profesjonalne, nowoczesne CV w formacie Word (`.docx`) dla stanowiska **trenera personalnego**.

## Pliki

- `CV_Ernest_Kurdziel.docx` – gotowe CV do otwarcia w programie Microsoft Word / Google Docs / LibreOffice.
- `generate_cv.py` – skrypt generujący plik CV.

## Jak wygenerować ponownie

```bash
pip install python-docx
python3 generate_cv.py
```

Skrypt utworzy plik `CV_Ernest_Kurdziel.docx` w bieżącym katalogu.

## Uwagi

- W lewej kolumnie jest zarezerwowane miejsce na zdjęcie (`[ MIEJSCE NA ZDJĘCIE ]`) – wystarczy wstawić własną fotografię.
- Treść (dane, doświadczenie, umiejętności) można łatwo edytować w pliku `generate_cv.py` i wygenerować dokument od nowa albo bezpośrednio w pliku `.docx`.
